# Wanderlust – Property Listing Platform

Wanderlust is a full stack property listing platform where users can create, browse and manage property listings like rooms, hotels and villas for their next travel destination.

## 🔗 Live Demo
https://wanderlust-v8sc.onrender.com/listings

## ✨ Features
- 🏠 CRUD operations on 30+ property listings
- 🔐 Secure user authentication and authorization using Passport.js
- 🖼️ Cloud-based image storage using Cloudinary
- 🗺️ Interactive location maps using Mapbox
- ⭐ User review and rating system
- 🔍 Search and filter functionality
- 📱 Fully responsive frontend

## 🛠️ Tech Stack
**Frontend:** HTML, CSS, JavaScript, Bootstrap, EJS Templating

**Backend:** Node.js, Express.js

**Database:** MongoDB, MongoDB Atlas

**Auth:** Passport.js, Express-Session

**Storage:** Cloudinary

**Maps:** Mapbox

**Deployment:** Render
